## Key Decisions

**Why no framework?**  
A marketing page doesn't need React. Vanilla HTML with Tailwind 
gives maximum performance with zero framework overhead.

**Why Tailwind over custom CSS?**  
PurgeCSS removes every unused class at build time — 
the final CSS bundle is minimal.
